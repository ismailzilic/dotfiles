# dotfiles

Hyprland (Lua config) + Neovim + Zsh setup on AMD hardware. Dark-themed, minimal, vi-centric.

## What's here

- **Zsh** (`zsh/`) — Zinit, fzf-tab, zoxide, pure prompt, vi mode
- **Hyprland** (`.config/hypr/`) — Lua modules, no gaps/animations/rounding
- **Neovim** (`.config/nvim/`) — lazy.nvim, LSP, DAP, Telescope, Treesitter
- **Kitty** (`.config/kitty/`) — ComicShannsMono Nerd Font
- **Tmux** (`.config/tmux/`) — Alt-Space prefix, vi keys
- **Rofi** (`.config/rofi/`) — Power menu, power profile selector
- **Waybar** (`.config/waybar/`) — Custom scripts for CPU/GPU/audio/IP
- **Dunst** (`.config/dunst/`) — Minimal notifications
- **EasyEffects** (`.config/easyeffects/`) — Voice noise reduction + music chain

## Keybinds (Hyprland)

- `Super + Q` — Kitty
- `Super + E` — Dolphin
- `Super + F` — Rofi
- `Super + U` — Screenshot (Hyprshot)
- `Super + P` — Power menu
- `Super + W` — Random wallpaper
- `Super + Shift + H/L` — Move workspace between monitors
- `hjkl` — Focus (with Super)
